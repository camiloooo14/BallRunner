# 🏃‍♂️ Ball Runner

**Desarrollado por:** Juan Camilo Villa Correa

## 📋 Descripción del Proyecto

**Ball Runner** es un juego de plataformas en 3D donde controlas una esfera que avanza rápidamente por una pista llena de obstáculos. Tu misión es esquivar obstáculos, mantener tu velocidad y evitar ser alcanzado por un enemigo que te persigue. El juego ofrece una progresión de niveles diseñada para desafiar tus habilidades y reflejos, proporcionando una experiencia de juego intensa y emocionante.

## 🎮 Mecánica Principal

El jugador controla una esfera que avanza en línea recta usando las flechas del teclado. Las mecánicas básicas incluyen:

* **Movimiento lateral** para esquivar obstáculos.
* **Reducción de velocidad** al chocar con objetos.
* **Persecución constante** por un enemigo que aumenta la tensión del juego.

El objetivo es llegar a la meta sin ser alcanzado por el enemigo. Si el enemigo toca al jugador, el juego termina.

## 🗺️ Progresión de Niveles

El juego cuenta con cinco niveles, cada uno con un diseño único que introduce nuevos retos:

1. **Nivel 1:** Persecución básica con obstáculos que reducen la velocidad.
2. **Nivel 2:** Introduce paredes que limitan el espacio para esquivar obstáculos.
3. **Nivel 3:** El jugador puede caer fuera de la pista, agregando riesgo adicional.
4. **Nivel 4:** Se agregan huecos en la pista, obligando a mayor precisión.
5. **Nivel 5:** Combina todos los elementos anteriores con paredes móviles y caminos estrechos para un desafío extremo.

## 📐 Diseño del Juego

El diseño del juego incluye elementos como:

* **Obstáculos móviles** y **paredes dinámicas**.
* **Efectos de velocidad y física realistas**.
* **Niveles progresivamente más difíciles**.

## 🚀 Cómo Jugar

1. Usa las flechas del teclado para mover la esfera hacia los lados.
2. Evita los obstáculos y mantén tu velocidad para no ser atrapado.
3. Llega a la línea de meta para ganar el nivel.

## ⚙️ Requisitos del Sistema

* Unity 2021 o superior.
* Sistema operativo Windows, macOS o Linux.
* Tarjeta gráfica compatible con DirectX 11 o superior.

## 🛠️ Instalación y Configuración

1. Clona este repositorio:

```
git clone https://github.com/tu-usuario/BallRunner.git
```

2. Abre el proyecto en Unity.
3. Asegúrate de importar todos los paquetes requeridos.
4. Presiona **Play** para iniciar el juego.
